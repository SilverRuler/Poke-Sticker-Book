[포켓몬 띠부씰 도감 프로젝트 개발 일지]
```bash
1. 프로젝트 시작 (v1.0 기초)
- 목표: 띠부띠부씰 수집 현황을 관리할 수 있는 웹 페이지 구축.
- 기술 스택: React(TypeScript) + Vite, Node.js(Express) 백엔드.
- 주요 기능:
  * 포켓몬 등록 (번호 및 이름 검색 지원).
  * 중복 확인 및 보유 수량 관리.
  * 도감 보기 및 삭제 기능.
  * 초기 데이터: 1번(이상해씨) ~ 1025번(복숭악동) 한글 이름 및 이미지 매핑.

2. 기능 고도화 및 UI 최적화
- 인증 시스템: 관리자 로그인(아이디/비밀번호) 기능을 추가하여 등록/삭제 권한 분리.
- 디자인: 모바일 최적화 반응형 그리드 레이아웃, 포켓몬 타입(속성)별 배지 표기 및 고유 색상 적용.
- 예정 도감: 실제 획득 전 미리 리스트업 할 수 있는 '예정 도감' 탭 추가.
- 배경음악(BGM): bgm.mp3 탑재 및 사용자 첫 상호작용 시 자동 재생 로직 구현.

3. 사용자 경험(UX) 및 보안 강화
- 커스텀 모달: 브라우저 기본 다이얼로그(alert, prompt)를 리액트 기반 커스텀 모달로 대체하여 모바일 보안 경고 해결 및 디자인 통일.
- 데이터 보존: 로컬 스토리지가 아닌 서버 사이드 JSON(data.json) 및 Redis 저장 방식으로 변경하여 기기간 동기화 구현.
- 보안: 비밀번호를 프론트엔드가 아닌 서버에서 검증하도록 수정, .gitignore를 통한 민감 정보 유출 방지.

4. Vercel 배포 및 최적화 (v1.1)
- Redis 연동: Vercel 서버리스 환경을 위해 Upstash Redis 지원 (poke_ 접두사로 키 충돌 방지).
- 이미지 로컬화: 외부 서버 다운에 대비하여 모든 포켓몬 이미지를 public/images/pokemon으로 다운로드 및 연동.
- 특별 스티커: 도감 번호 외 '특별' 카테고리(피카츄 메타몽 등) 추가.
- 방문자 카운터: IP 기반 중복 없는 Today/Total 카운터 구현 및 Vercel 배포 봇 차단 로직 적용.
- 자동 초기화: 한국 시간(KST) 00시 기준 '오늘의 획득' 및 'Today 방문자' 자동 리셋.

5. 최종 UI 디테일
- 헤더 레이아웃 재배치 (BGM/로그인 버튼 중앙 정렬).
- 모바일 가독성을 위한 서브타이틀 줄바꿈 처리.
- '오늘의 획득' 날짜 박스와 초기화 버튼의 크기 및 디자인 통일화.

6. 공식 폼 데이터 전수 조사 및 이미지 자산 통합 (v1.2)
- 쉐이미(#492) 폼 분리: 랜드폼과 스카이폼을 개별 데이터로 등록하고 각각의 이미지를 연동하여 검색 및 수집 최적화.
- 공식 특수 폼 대거 추가: 테오키스(4종), 로토무(6종), 지가르데(4종), 네크로즈마(4종), 큐레무(3종) 등 누락되었던 수백 개의 공식 특수 폼 및 리전 폼 반영.
- 성별 및 개체 차이 구현: 냐오닉스, 켄호로우, 탱그릴, 화염레오 등의 성별에 따른 외형 차이를 별도 데이터로 분리.
- 속성별 폼 추가: 아르세우스와 실버디의 18가지 모든 타입별 모습 데이터를 생성하여 도감의 완결성 확보.
- 9세대 최신 데이터 반영: 파밀리쥐(가족 수), 시비꼬(색상), 노고고치(마디 수), 차데스/그우린차(진품/가품), 오거폰(가면), 테라파고스(폼) 등 최신 세대 데이터 보완.
- 전설의 포켓몬 오리진폼 추가: 디아루가, 펄기아, 기라티나의 오리진폼 데이터 및 이미지 연동.
- 피카츄 캡 폼 추가: 오리지널캡부터 월드캡까지 총 8종의 모자 쓴 피카츄 데이터 반영.
- 이미지 자산 자동화 확보: 공식 서버 이미지 크롤링 스크립트를 작성하여 80여 개의 신규 고화질 PNG 파일을 프로젝트 내 public 경로에 통합.
- 빌드 안정성 강화: 대규모 데이터 업데이트에 따른 문법 오류 전수 수정 및 로컬 빌드 테스트를 통한 안정성 검증.

7. 고도화된 데이터 크롤링 전략 (Crawling Strategy)
- 9세대 데이터 한글화(v1.3): 영어로 남아있던 899번~1025번 포켓몬의 상세 정보(분류, 특성, 도감 설명)를 공식 한글 데이터로 전수 교정.
- 멀티 소스 교차 검증: 공식 사이트(pokemonkorea.co.kr), 전문 위키(나무위키, 포켓몬 위키), 글로벌 API(PokeAPI)를 결합하여 데이터의 신뢰도 확보.
- 내부 ID 우회 전략: 공식 사이트의 전국도감 번호와 다른 '내부 관리 번호'를 자동 추적하여 상세 페이지 접근 및 데이터 추출 성공.
- 파이썬 배치 처리: 대량의 JSON 데이터를 파이썬 스크립트를 통해 원자적(Atomic)으로 주입하여 수동 수정에 따른 오류 방지 및 속도 개선.
- 최종 전수 검사: grep 엔진을 활용한 데이터 무결성 검사로 영문 텍스트 잔존 여부를 0.1%까지 완벽하게 스캔 및 보완.

[주요 데이터 출처]
- 공식 도감: https://pokemonkorea.co.kr/pokedex
- 이미지 서버: https://data1.pokemonkorea.co.kr

- Language: TypeScript
- Frontend: React (Vite)
- Backend: Node.js (Express)
- Database: Upstash Redis
- Deployment: Vercel
- Assets: Localized Image Library (1025+ forms)
```
